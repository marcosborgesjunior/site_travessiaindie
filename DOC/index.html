HLTV — Jogos do Brasil

Scraper que varre o hltv.org/matches, filtra os jogos com times brasileiros e publica um JSON com horários, séries de mapas, stats, MVP e dados do campeonato.

JSON públicohttps://www.travessiaindie.com.br/brazil-matches.json
FusoAmerica/Sao_Paulo (epoch data-unix convertido)
Atualizaçãocron diário 00:10 BRT (GitHub Actions → Pages)
Fontes/matches + /events + páginas dos matches BR

1. Regras de coleta anti-estresse

RegraValorAjuste
CacheNenhum — cada execução busca fresco—
Limite de chamadas20 por execução (corta o resto)--max-calls
Ritmo mínimo1 request a cada 2 minutos--interval (seg)
Contadorcampo http_calls no JSON—
Falha em página de matchnão derruba o run (perde só aquele match)—
Falha no índice /eventsnão derruba o run (perde só event_info)—
⏱️ Ritmo típico de um run 1 (/matches) + 1 (/events) + ~10 páginas de match ≈ 12 chamadas
duração ≈ 25 min → JSON publicado por volta de 00:35 BRT.
🚫 Cloudflare O HLTV bloqueia rajadas. Se aparecer 403 / "Just a moment", a execução aborta com aviso e não retenta. O limite de chamadas é inegociável.

Detecção de time brasileiro (ordem de verificação)

  1. Bandeira no markup — img[src$="BR.gif"] ou title="Brazil"
  2. Fallback por nome — o HLTV nem sempre renderiza bandeira. Nome (case-insensitive) na lista BR_TEAM_NAMES: furia, mibr, imperial, pain, legacy, fluxo, red canids, godsent, sharks, intz, w7m, case, havan libre, kabum, los héroes, br crowd + qualquer nome terminado em " br" (ex.: Low Cortisol BR)
  3. Exceção manual — BR_EXCLUDED_NAMES = {"bestia"}: sobrepõe até a bandeira do HLTV (o site mostra BR errado; Bestia é argentina)

Um match entra no JSON se qualquer um dos dois times for BR.

4. Integração front

CORS & cache

GET https://www.travessiaindie.com.br/brazil-matches.json

Content-Type: application/json; charset=utf-8
Access-Control-Allow-Origin: *        ← CORS liberado (qualquer origem)
Cache-Control: max-age=600            ← CDN guarda 10 min
⚠️ Cache do CDN (10 min) Para forçar versão nova na mão: adicione ?cb=1 no fim da URL. Em produção não precisa — basta buscar de novo a cada atualização do seu front.

Exemplo mínimo (vanilla JS)

const URL = "https://www.travessiaindie.com.br/brazil-matches.json";

async function carregar() {
  const r = await fetch(URL, { cache: "no-store" });
  const data = await r.json();

  // 1) Jogos de hoje
  const hoje = data.days.find(d => d.date === new Date().toISOString().slice(0, 10))
            ?? data.days[0];

  // 2) Ao vivo agora
  for (const m of data.live) {
    const placar = Object.entries(m.score?.rounds ?? {})
      .map(([t, v]) => `${t} ${v}`).join(" x ");
    console.log(`AO VIVO: ${placar}`);
  }

  // 3) Agenda do dia com séries e MVP
  for (const m of hoje.matches) {
    const br  = m.teams.filter(t => t.is_brazil).map(t => t.name);
    const adv = m.teams.filter(t => !t.is_brazil).map(t => t.name);
    const mapa  = m.series?.current_map ? ` [${m.series.current_map}]` : "";
    const mvp   = m.mvp ? ` MVP: ${m.mvp.nick} (${m.mvp.rating})` : "";
    console.log(`${m.time} ${br} x ${adv}${mapa} — ${m.event}${mvp}`);
  }

  return data;
}

React

function useJogosBR() {
  const [data, setData] = useState(null);
  useEffect(() => {
    fetch("https://www.travessiaindie.com.br/brazil-matches.json")
      .then(r => r.json())
      .then(setData);
  }, []);
  return data;   // { live, days, total_matches, http_calls, ... }
}

6. Limitações conhecidas honestidade

  1. Highlights de vídeo — /highlights retorna 404 (removida no redesign) e a página de match não tem seção de highlights. Não há fonte HTML para melhores momentos.
  2. Tempo real — o scorebot usa websocket; nosso score é snapshot do momento da execução (atualiza a cada run do cron).
  3. Stats por mapa — os stats de jogador por mapa finalizado vêm do bloco embutido div#<mapstatsid>-content na página do match (zero requests). O mapa ao vivo ainda não tem esse bloco — aparece quando o mapa termina. A página dedicada /stats/matches/mapstatsid/... tem WAF próprio (403).
  4. Jogo ao vivo sem horário — entra só em live[], sem time (o markup não expõe o início).
  5. Cache do CDN — o JSON pode estar até 10 min atrás do scraped_at se o consumidor pegar o cache do edge.
